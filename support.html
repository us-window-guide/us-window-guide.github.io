Prepare to Troubleshoot a Windows Error

Collect the details that help narrow down a Windows error before attempting advanced repairs.

Record the exact error

Write down the complete error code and message, the Windows edition and version, and the action that triggered the problem. Note whether it occurred during an update, installation, activation, startup, file operation, or while using a device.

Note recent changes

Record recent Windows updates, driver installations, new applications, hardware changes, or network changes. Include the approximate date and whether the issue happens every time or only occasionally.

Try safe first checks

Check date and time, free disk space, network access, pending restarts, and visible Windows notifications. Use built-in troubleshooters where relevant. Avoid unknown scripts, registry cleaners, unofficial system files, or instructions that disable security features.

Get appropriate assistance

For advanced repair, activation, managed-device policies, or recovery issues, consult official Microsoft support resources or your organization's IT administrator. Never share passwords, product keys, BitLocker recovery keys, or private files in public support posts.
