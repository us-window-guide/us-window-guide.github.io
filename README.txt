WINDOWS ERROR CODE GUIDES WEBSITE

Includes:
- index.html: simple homepage
- blog.html: searchable directory of 77 error-code articles
- support.html: support preparation page
- articles/: 77 individual HTML guides
- sitemap.xml and robots.txt

Publishing:
1. Upload the contents of this folder to your hosting root.
2. Replace https://your-windows-error-domain.example in sitemap.xml and robots.txt with your published domain.
3. Keep the articles folder and relative paths intact.

Header:
The navbar contains Home and Articles links, plus exactly two 3D-style buttons: Fix and Support. Both buttons display on-page guidance and do not redirect externally.

Content:
Independent educational content. Windows error codes can have different causes depending on the Windows version and component reporting the error. Follow official Microsoft guidance for advanced repairs. This website is not affiliated with Microsoft.
